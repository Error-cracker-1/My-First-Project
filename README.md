This repository is a versatile platform integrating beginner-friendly coding projects with an AI-powered code review and reporting system. It features small experiments in HTML, CSS, JavaScript, Python, PowerShell, and Jupyter Notebook, alongside a Python Flask web application for daily AI code reviews. The GitHub Pages site hosts browser-based projects and a dynamic AI review dashboard.

## Getting Started

Install dependencies with `pip install -r requirements.txt`. The Flask application can be started with `npm start` or `PORT=3000 python3 -m web.app`.

## Learning Focus

This repository is useful for practicing HTML, CSS, JavaScript, beginner game development, Python, Flask, Jupyter, PowerShell, AI integration, web dashboards, Dev Containers, and GitHub Pages.

## Repository Notes

This is a practice environment containing small exercises alongside more complete applications. The `docs` folder hosts the public GitHub Pages site and AI review dashboard.
